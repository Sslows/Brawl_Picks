# Brawl Picks AI — стартовый проект

Telegram-бот на Python + aiogram 3. Показывает ротацию из официального Brawl Stars API и даёт предварительные рекомендации. Не выдумывает статистику: если API не отдал статистику по карте, бот явно пишет, что пики являются общими тактическими вариантами, а не рейтингом по win rate.

## Что нужно

- Telegram-бот, созданный через `@BotFather`
- API-токен Supercell из https://developer.brawlstars.com/
- Сервер Linux с Docker и Docker Compose (для режима 24/7)

## Настройка

1. Создай бота через `@BotFather` командой `/newbot`, скопируй токен.
2. Войди на официальный портал Brawl Stars API, создай ключ и добавь сервер/IP согласно требованиям портала.
3. Скопируй `.env.example` в `.env`.
4. Заполни оба значения в `.env`. Не публикуй токены и не отправляй их другим людям.
5. Запусти:

```bash
docker compose up -d --build
docker compose logs -f
```

6. Открой Telegram, найди своего бота и отправь `/start`.

## Команды

- `/start` — главное меню
- `/maps` — текущие карты и пики

## Как остановить / обновить

```bash
docker compose down
docker compose up -d --build
```

## Ограничения этой первой версии

- Текущая ротация берётся из официального endpoint `GET https://api.brawlstars.com/v1/events/rotation`.
- Официальный API может не предоставлять статистику побед/популярности бойцов по карте. В таком случае бот не подставляет выдуманные проценты.
- Тактические списки — стартовые общие рекомендации по режиму, а не вычисленная статистика меты. Чтобы ранжировать бойцов на конкретной карте, потребуется надёжный источник map-specific battle stats и согласованная схема обновления.
- Анализ пикселей карты, контрпики под конкретный вражеский драфт и данные о билдах — следующие этапы, не реализованы в этой версии.
- Неофициальные источники могут менять структуру и условия доступа; проверяй их правила перед интеграцией.

## Источники

- Официальный API: https://developer.brawlstars.com/
- Live rotation / статистика карт Brawlify: https://brawlify.com/events
- Справочник данных BrawlAPI: https://brawlapi.com/ (его статический `/v1/events` не является live-ротацией)

## Диагностика

Если бот сообщает, что API недоступен:
- проверь токен Supercell и настройки ключа;
- проверь, что сервер может подключаться к `api.brawlstars.com`;
- проверь логи `docker compose logs -f`;
- не подменяй ошибку заранее сохранёнными картами: это будет не актуальная ротация.
