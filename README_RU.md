# Brawl Picks AI — обновлённая версия

Telegram-бот на Python + aiogram 3. Использует два источника:

- **BrawlAPI** — каталог карт и бойцов, без API-ключа: https://brawlapi.com/
- **BrawlPick** — наблюдаемая статистика бойцов на картах, если для карты доступна таблица: https://www.brawlpick.app/map-stats

Ключ Supercell для этой версии не нужен. Нужен только токен Telegram-бота от `@BotFather`.

## Команды

- `/start` — меню и справка
- `/maps` — каталог карт (это не подтверждённая live-ротация событий)
- `/map Safe Zone` — поиск карты в каталоге
- `/pick Safe Zone` — статистика бойцов по карте
- `/brawlers` — список бойцов
- `/about` — источники и дата обновления статистики

Названия карт для `/pick` вводи на английском, как на сайте BrawlPick. Например: `/pick Safe Zone`.

## Настройка

1. Установи зависимости из `requirements.txt`.
2. Добавь в переменные окружения хостинга `TELEGRAM_BOT_TOKEN` со своим токеном от BotFather.
3. Запусти `python bot.py`.

Не публикуй токен и не отправляй его в чаты.

## Важно про статистику

- BrawlAPI — статический справочник, а не live-ротация событий.
- BrawlPick обновляет собранную статистику после поступления достаточного количества новых матчей; расписание не фиксировано.
- Проценты в ответах — наблюдаемые результаты матчей, не гарантия победы.
- Структура стороннего сайта может измениться. Если бот не распознаёт таблицу, он должен сообщить об этом и дать ссылку на источник, а не придумывать цифры.
- Источники не принадлежат Supercell.
